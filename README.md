# 📊 Sales & Performance Dashboard

An interactive and dynamic data analytics dashboard built to track key sales metrics, regional distribution, and product profitability. This project transforms raw commercial sales data into actionable business insights.

---

## 📸 Dashboard Overview

![Sales Dashboard](dashboard_screenshot.png)

---

## 🔑 Key Features & Highlights

* **Dynamic KPI Tracking:** Real-time updates for Total Sales ($1.4M), Total Quantity (51K), and Total Orders (2K).
* **Category Analysis:** Comprehensive breakdown of sales volume and order counts across categories (Beverages, Dairy Products, Meat & Poultry, etc.).
* **Sales Trends & Seasonality:** Visual representation of yearly order trends (2013–2015) and sales distribution by country.
* **Interactive Slicers:** Full cross-filtering functionality by **Country** and **Category** using dynamic linkage (`SUBTOTAL` & PivotTable connections).

---

## 🛠️ Tech Stack & Tools

* **Data Analytics & Visualization:** Microsoft Power BI / Excel (PivotTables, Power Query, Slicers, Custom Formatting)
* **Data Modeling:** Calculated measures, dynamic range references, and KPI aggregations
* **Version Control:** Git & GitHub
